# Resource: signalfx_observability_chart

Use this resource to manage a reusable modern Chart Template. Configure exactly one of `metrics_time_series`, `metrics_single_value`, `metrics_list`, `metrics_table`, `metrics_cluster_map`, or `text`. Reference its `id` from a `signalfx_observability_dashboard` panel to place the chart on a dashboard. Folder placement is managed separately by `signalfx_observability_directory`.

The required resource `title` names the saved Template. The optional `title` inside the selected chart controls its display title. These titles are independent.

Updates replace the complete saved Chart document. Unsupported fields are absent from Terraform state and are discarded on update; the provider warns which fields are affected. Copy UI changes you want to keep into Terraform before applying. For chart types or fields outside the typed schema, use `signalfx_observability_template` with `root_element = "Chart"` and the full `spec`.

## Example

```terraform
resource "signalfx_observability_chart" "request_rate" {
  title = "Reusable request rate"

  metrics_time_series = {
    title         = "Request rate"
    program       = "A = data('requests.count').sum().publish('A')"
    time_range    = "1h"
    visualization = "line"

    series = {
      A = {
        name = "Requests"
        display_unit = {
          suffix = "/s"
        }
      }
    }
  }
}

resource "signalfx_observability_dashboard" "service" {
  title = "Service overview"

  container = [{
    template_id = signalfx_observability_chart.request_rate.id
  }]
}
```

Each metric chart requires a nonempty SignalFlow `program`. The optional `time_range` accepts a positive whole-number duration such as `15m`, `60m`, or `1h`. A dashboard's selected time range takes precedence when the chart is displayed there. Equivalent duration spellings remain stable on refresh; changing only the configured spelling can cause one in-place update. Text charts use optional `markdown` and do not require a program.

### Single value

```terraform
resource "signalfx_observability_chart" "request_total" {
  title = "Request total"

  metrics_single_value = {
    program                 = "A = data('requests.count').sum().publish('A')"
    time_range              = "15m"
    maximum_fraction_digits = 0
    display_unit            = { suffix = " requests" }
  }
}
```

### List

```terraform
resource "signalfx_observability_chart" "requests_by_host" {
  title = "Requests by host"

  metrics_list = {
    program        = "A = data('requests.count').sum(by=['host']).publish('A')"
    display_fields = [{ property = "host", enabled = true }]
    sort           = { by = "value", direction = "desc" }
  }
}
```

### Table

```terraform
resource "signalfx_observability_chart" "request_table" {
  title = "Request table"

  metrics_table = {
    program  = "A = data('requests.count').sum(by=['host']).publish('A')"
    group_by = ["host"]
    columns = [{
      field        = "A"
      header_name  = "Requests"
      display_unit = { suffix = " requests" }
    }]
  }
}
```

### Cluster map

```terraform
resource "signalfx_observability_chart" "request_clusters" {
  title = "Request clusters"

  metrics_cluster_map = {
    program     = "A = data('requests.count').sum(by=['host']).publish('A')"
    group_by    = ["host"]
    color_by    = "Range"
    color_range = { palette = "temperature" }
  }
}
```

### Text

```terraform
resource "signalfx_observability_chart" "runbook" {
  title = "Service runbook"

  text = {
    title    = "Troubleshooting"
    markdown = "## Request rate\nCompare the request charts before investigating individual hosts."
  }
}
```

## Import

Import an existing supported Chart by its bare Template ID, not a URL or `/v2/template/...` API reference:

```shell
terraform import signalfx_observability_chart.request_rate G47WjI1AABc
```

Import reads supported fields without changing the saved chart. Any later update discards unsupported fields. The saved Template must have a `Chart` root and one supported chart element. Metric charts must contain a nonempty SignalFlow program. Use the generic Template resource to manage unsupported content.
